# Dossier Analyses UML

Ce dossier contient les diagrammes UML de la phase d'analyse du systeme DataPipe.

## Contenu

- `01_contexte_systeme.puml` : diagramme de contexte (acteurs et systemes externes)
- `02_packages_analyse.puml` : diagramme de packages (vue fonctionnelle API)
- `03_use_cases.puml` : diagramme de cas d'usage
- `04_classes_metier.puml` : diagramme de classes metier

## Generation (optionnel)

Si PlantUML est installe :

- `plantuml analyses/01_contexte_systeme.puml`
- `plantuml analyses/02_packages_analyse.puml`
- `plantuml analyses/03_use_cases.puml`
- `plantuml analyses/04_classes_metier.puml`
